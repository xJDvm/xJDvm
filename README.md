### Cómo pienso

- **Decido con trade-offs explícitos.** Cada decisión de arquitectura lleva su problema, alternativas y lo que se sacrifica.
- **Los costos son parte del diseño.** Por ejemplo, evitar un NAT Gateway con la Data API de Aurora, o resolver las preguntas frecuentes sin llamar a un LLM.
- **Mido antes de afirmar.** Si no hay cifra, no la invento.
